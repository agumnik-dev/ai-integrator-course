Часть 2

Как устроен вызов LLM

Вызов Claude API — это обычный HTTP-запрос. Вы отправляете список сообщений и получаете ответ. Модель не помнит прошлых запросов: всю историю диалога вы каждый раз присылаете сами. Это главное, что нужно запомнить в первый день.

import anthropic
from dotenv import load_dotenv

load_dotenv()                      # читает .env, кладёт ключ в переменные окружения
client = anthropic.Anthropic()     # сам находит ANTHROPIC_API_KEY

response = client.messages.create(
    model="claude-haiku-5-5",      # самая быстрая и дешёвая модель — для учёбы
    max_tokens=500,                # потолок длины ответа
    messages=[{"role": "user", "content": "Что такое MCP? Два предложения."}],
)

print(response.content[0].text)
print(response.usage.input_tokens, response.usage.output_tokens)

Три вещи в ответе, на которые смотрит профессионал:

  • content: список блоков. Пока там один текстовый блок, позже появятся вызовы инструментов.
  • usage: сколько токенов ушло на вход и выход. Из этого считается стоимость. Заказчик всегда спросит, сколько стоит обработка одного письма.
  • stop_reason: почему модель остановилась. end_turn означает, что закончила сама, а max_tokens — что ответ обрезан.

Правило №1 профессии. Ключ API живёт только в .env, а .env никогда не попадает в git. Ключ, случайно отправленный в публичный репозиторий, боты находят за минуты. Если это случилось, ключ сразу отзывается в консоли и создаётся новый.

Часть 3

Установка, шаг за шагом

Все команды выполняются в Terminal. Если какая-то команда выдала ошибку, пришлите мне её текст целиком.

  1. Проверьте базовые инструменты

    git --version
brew --version

    Если brew не найден, поставьте Homebrew командой с сайта brew.sh.

  2. Поставьте uv и GitHub CLI

    brew install uv gh
uv --version

  3. Войдите в GitHub из терминала

    gh auth login

    Выберите GitHub.com, HTTPS, вход через браузер. Аккаунт agumnik-dev.

  4. Создайте проект в папке курса

    cd ~/Documents/ai-integrator-course
uv init --python 3.12 --name ai-integrator-course
uv add anthropic python-dotenv pydantic
uv add --dev ruff pytest
mkdir -p 00-setup lessons
rm -f main.py hello.py

    uv init создаст pyproject.toml, .python-version, .gitignore и git-репозиторий. Если уже есть .git, он его не тронет.

  5. Закройте секреты от git

    echo ".env" >> .gitignore
cat .gitignore

    В выводе должны быть строки .venv и .env.

  6. Положите ключ API

    Создайте файл .env (в редакторе, не через историю терминала):

    ANTHROPIC_API_KEY=sk-ant-...ваш ключ...

    И файл-образец .env.example, который пойдёт в git и покажет другим, какие переменные нужны:

    ANTHROPIC_API_KEY=

    В console.anthropic.com в разделе Limits поставьте месячный лимит расходов, например $20. Так ошибка в цикле не превратится в большой счёт.

  7. Первый коммит и репозиторий на GitHub

git branch -M main                     # главная ветка называется main

gh repo create ai-integrator-course --public --source=. --remote=origin --push

    Репозиторий публичный, чтобы я мог его читать для ревью и чтобы работодатель видел вашу активность. Секретов в нём нет.

Задание урока 0

Скрипт hello_claude.py

Напишите в папке 00-setup/ консольную утилиту, которая задаёт вопрос Claude и показывает не только ответ, но и «счёт за услугу». Это первая версия того, что вы будете делать для заказчиков: вызов модели с контролем стоимости и понятными ошибками.

Как запускается

uv run python 00-setup/hello_claude.py "Что такое MCP? Ответь коротко."

Что должно получиться

MCP (Model Context Protocol) — открытый стандарт...

---
Модель:        claude-haiku-5-5
Токены:        вход 18, выход 74
Стоимость:     $0.000390
Остановка:     end_turn

Требования

  • Вопрос берётся из аргумента командной строки. Если аргумента нет, скрипт печатает подсказку по использованию и завершается с кодом 1.
  • Если ключа нет в окружении, скрипт пишет понятное сообщение («Не найден ANTHROPIC_API_KEY, создайте файл .env») и завершается с кодом 1, без длинного traceback.
  • Стоимость считает отдельная функция estimate_cost(input_tokens, output_tokens). Цены за миллион токенов возьмите со страницы цен Anthropic и вынесите в константы в начале файла.
  • Ошибки API перехватываются: неверный ключ, превышение лимита, нет сети. Пользователь видит одну понятную строку, а не трассировку.
  • Если stop_reason равен max_tokens, выводится предупреждение, что ответ обрезан.
  • Тест 00-setup/test_hello_claude.py проверяет estimate_cost минимум на двух случаях, включая нулевые токены. Тест не должен ходить в API.
  • Код проходит uv run ruff check и uv run ruff format --check.
  • У всех функций есть type hints.

Со звёздочкой, если есть время

  • Флаг --system "..." для системного промпта. Задайте один вопрос с системным промптом «Отвечай как страховой агент, на иврите» и без него, сравните.
  • Флаг --model для выбора модели. Сравните цену и качество ответа Haiku и Sonnet на одном вопросе.

Самопроверка

Вопросы перед следующим уроком

Модель «помнит» предыдущий вопрос, если вызвать скрипт второй раз?

Нет. Каждый вызов API независим. Чтобы вести диалог, нужно самим хранить историю и присылать её целиком в messages. Поэтому длинные диалоги дорожают: каждый раз оплачивается вся история.

Почему uv.lock коммитим, а .venv нет?

uv.lock фиксирует точные версии, чтобы у всех и на сервере ставилось одно и то же. .venv — это установленные файлы, их всегда можно восстановить командой uv sync. Как package-lock.json и node_modules.

Почему выход стоит дороже входа?

Входные токены модель обрабатывает параллельно, а выходные генерирует по одному. Отсюда практическое правило: просите короткие ответы и структурированный вывод, когда длинный текст не нужен.

Что делать, если ключ попал в публичный репозиторий?

Сразу отозвать ключ в консоли и создать новый. Удаление коммита не помогает: ключ уже могли скопировать, а история git хранит всё.
